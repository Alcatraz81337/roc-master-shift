# Инструкция по публикации на GitHub Pages

Это пошаговая инструкция по публикации ROC Analytics Dashboard на GitHub Pages для решения проблемы CORS и обеспечения корректной работы синхронизации с Google Таблицами.

## 🎯 Зачем это нужно?

При открытии HTML файла напрямую из файловой системы (`file://`) браузер блокирует запросы к Google Sheets API из-за политики CORS. Публикация на GitHub Pages решает эту проблему, так как:
- Файлы обслуживаются через HTTPS
- Домен `github.io` разрешен для запросов к Google Sheets API
- Дашборд доступен из любого места через интернет

## 📋 Предварительные требования

1. Аккаунт на GitHub (если нет - создайте на [github.com](https://github.com))
2. Git установлен на вашем компьютере
3. Все файлы проекта готовы:
   - `index.html`
   - `roc_logo.png`
   - `emco_logo.png`
   - `photos/` (папка с аватарами)

## 🚀 Вариант 1: Через веб-интерфейс GitHub (проще)

### Шаг 1: Создание репозитория

1. Войдите в свой аккаунт GitHub
2. Нажмите кнопку **"+"** в правом верхнем углу → **"New repository"**
3. Заполните форму:
   - **Repository name**: `roc-analytics-dashboard` (или любое другое имя)
   - **Description**: "ROC Analytics Dashboard - интерактивный дашборд для визуализации аналитики"
   - **Visibility**: Public (для бесплатного GitHub Pages) или Private (требует GitHub Pro)
   - **НЕ** ставьте галочки на "Add a README file", "Add .gitignore", "Choose a license"
4. Нажмите **"Create repository"**

### Шаг 2: Загрузка файлов

1. На странице созданного репозитория найдите раздел **"uploading an existing file"**
2. Нажмите **"uploading an existing file"**
3. Перетащите или выберите следующие файлы:
   - `index.html`
   - `roc_logo.png`
   - `emco_logo.png`
   - `README.md`
   - `METRICS_MAPPING.md` (опционально)
   - `GITHUB_PAGES_SETUP.md` (опционально)
4. Для папки `photos/`:
   - Нажмите **"Add file"** → **"Upload files"**
   - Перетащите всю папку `photos/` или отдельные файлы из неё
5. Прокрутите вниз, введите сообщение коммита: `Initial commit: ROC Analytics Dashboard`
6. Нажмите **"Commit changes"**

### Шаг 3: Настройка GitHub Pages

1. В репозитории перейдите в **Settings** (вкладка в верхнем меню)
2. В левом меню найдите раздел **"Pages"** (в секции "Code and automation")
3. В разделе **"Source"**:
   - Выберите ветку: **`main`** (или `master`, если используется она)
   - Выберите папку: **`/ (root)`**
4. Нажмите **"Save"**
5. Подождите 1-2 минуты

### Шаг 4: Получение URL

1. После сохранения настроек GitHub покажет URL вашего сайта:
   ```
   https://[ваш-username].github.io/[название-репозитория]/
   ```
   Например: `https://username.github.io/roc-analytics-dashboard/`
2. Скопируйте этот URL
3. Через 1-2 минуты откройте его в браузере - дашборд должен загрузиться!

## 🔧 Вариант 2: Через командную строку (для продвинутых)

### Шаг 1: Инициализация Git репозитория

Откройте терминал (PowerShell, Command Prompt или Git Bash) в папке проекта:

```bash
# Перейдите в папку проекта
cd "c:\Users\Golovinvn\ROC\03 Resources\Cursor\02_MASTER-SHIFT-SUR"

# Инициализируйте git репозиторий
git init

# Добавьте все необходимые файлы (одной командой)
git add .

# Создайте начальный коммит
git commit -m "Initial commit: ROC Analytics Dashboard"
```

### Шаг 2: Создание репозитория на GitHub

1. Создайте новый репозиторий на GitHub (см. Вариант 1, Шаг 1)
2. **НЕ** инициализируйте его с README, .gitignore или лицензией

### Шаг 3: Подключение и отправка

В терминале выполните (замените `[ваш-username]` и `[название-репозитория]` на реальные значения):

```bash
# Добавьте удаленный репозиторий
git remote add origin https://github.com/[ваш-username]/[название-репозитория].git

# Переименуйте ветку в main (если нужно)
git branch -M main

# Отправьте код на GitHub
git push -u origin main
```

### Шаг 4: Настройка GitHub Pages

Следуйте инструкциям из Варианта 1, Шаг 3.

## ✅ Проверка работы

После публикации:

1. Откройте URL вашего дашборда в браузере
2. Откройте консоль разработчика (F12) → вкладка **Console**
3. Проверьте, что:
   - Нет ошибок CORS
   - Данные загружаются из Google Таблицы
   - Метрики обновляются каждые 15 секунд

## 🔄 Обновление дашборда

### Через веб-интерфейс:
1. Откройте файл в репозитории на GitHub
2. Нажмите иконку карандаша (Edit)
3. Внесите изменения
4. Нажмите **"Commit changes"**
5. Изменения появятся на сайте через 1-2 минуты

### Через командную строку:
```bash
# Внесите изменения в файлы
# ...

# Добавьте изменения
git add .

# Создайте коммит
git commit -m "Описание изменений"

# Отправьте на GitHub
git push
```

## 🐛 Решение проблем

### Сайт не открывается (404)

- Подождите 2-3 минуты после настройки Pages
- Проверьте, что файл называется `index.html` (с маленькой буквы)
- Убедитесь, что файл находится в корне репозитория, а не в подпапке

### Изображения не загружаются

- Проверьте, что все файлы изображений загружены в репозиторий
- Убедитесь, что пути в `index.html` правильные (относительные, без `/` в начале)
- Проверьте, что папка `photos/` содержит все необходимые файлы

### Данные не загружаются из Google Таблицы

- Убедитесь, что Google Таблица опубликована для просмотра
- Проверьте ID таблицы в конфигурации `index.html` (строка ~610)
- Откройте консоль браузера (F12) и проверьте ошибки

### CORS ошибки все еще появляются

- Убедитесь, что вы открываете сайт через `https://[username].github.io/...`, а не через `file://`
- Очистите кэш браузера (Ctrl+Shift+Delete)
- Попробуйте открыть в режиме инкогнито

## 📝 Дополнительная информация

- GitHub Pages автоматически обновляет сайт при каждом коммите
- Изменения могут появиться с задержкой до 2-3 минут
- Для приватных репозиториев требуется GitHub Pro (платный план)
- Бесплатные GitHub Pages работают только для публичных репозиториев

После выполнения всех шагов ваш дашборд будет доступен по постоянному URL и будет корректно работать с Google Таблицами без проблем CORS.
