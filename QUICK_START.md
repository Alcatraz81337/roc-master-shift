## 🚀 Следующие шаги

### Если Git установлен:

Выполните в терминале (в папке проекта):

```bash
git init
git add .
git commit -m "Initial commit: ROC Analytics Dashboard"
```

Затем следуйте инструкциям в `GITHUB_PAGES_SETUP.md` (Вариант 2).

### Если Git НЕ установлен (или проще через веб-интерфейс):

1. Создайте репозиторий на GitHub (см. `GITHUB_PAGES_SETUP.md`, Вариант 1)
2. Загрузите файлы через веб-интерфейс:
   - `index.html`
   - `roc_logo.png`
   - `emco_logo.png`
   - `photos/` (всю папку)
   - `README.md`
   - `METRICS_MAPPING.md`
   - `GITHUB_PAGES_SETUP.md`
3. Настройте GitHub Pages (см. `GITHUB_PAGES_SETUP.md`)
