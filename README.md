# ROC Analytics Dashboard

Интерактивный дашборд для визуализации аналитики ROC (Мастер-смена) с автоматической синхронизацией данных из Google Таблиц.

## 🚀 Возможности

- **Автоматическое обновление**: Данные обновляются каждые 15 секунд
- **Визуализация метрик**: Отображение ключевых показателей по модулям BALANCE, RAM, MAS
- **Обработка ошибок**: Умная обработка сетевых ошибок с повторными попытками
- **Адаптивный дизайн**: Работает на всех устройствах (десктоп, планшет, мобильный)
- **Современный UI**: Glassmorphism дизайн с неоновыми акцентами

## 📋 Требования

- Современный браузер с поддержкой ES6+ (Chrome, Firefox, Safari, Edge)
- Google Таблица должна быть опубликована для просмотра (публичный доступ)
- Интернет-соединение для синхронизации данных

## 🔧 Настройка

### 1. Подготовка Google Таблицы

1. Откройте вашу Google Таблицу
2. Нажмите **"Настройки доступа"** (кнопка "Настроить доступ" в правом верхнем углу)
3. Установите доступ: **"Все, у кого есть ссылка"** или **"Публично в интернете"**
4. Скопируйте ID таблицы из URL:
   ```
   https://docs.google.com/spreadsheets/d/[ID_ТАБЛИЦЫ]/edit
   ```

### 2. Настройка дашборда

1. Откройте файл `index.html` в текстовом редакторе
2. Найдите строку с `SHEET_ID` в конфигурации (около строки 601):
   ```javascript
   SHEET_ID: '1JigB9dS_CEaDfdYbTH_6XJKXbnkuHuv8v5swGlg6bWI',
   ```
3. Замените ID на ID вашей таблицы
4. Сохраните файл

### 3. Структура Google Таблицы

Дашборд ожидает следующие листы в таблице:
- **Общие** - общие метрики (B2, B3, B4)
- **BALANCE** - метрики балансировки (B2-B7)
- **RAM** - метрики дорог (B2-B6)
- **MAS** - метрики простоев (N4-N7, B6-B7)

Подробное описание маппинга метрик см. в файле `METRICS_MAPPING.md`.

## 🌐 Публикация на GitHub Pages

### Вариант 1: Через веб-интерфейс GitHub

1. Создайте новый репозиторий на GitHub
2. Загрузите файлы:
   - `index.html` (главный файл)
   - `roc_logo.png` и `emco_logo.png` (логотипы)
   - `photos/` (папка с аватарами)
   - `README.md` и `METRICS_MAPPING.md` (опционально)
3. Перейдите в **Settings** → **Pages**
4. В разделе **Source** выберите ветку (обычно `main` или `master`)
5. Выберите папку `/ (root)`
6. Нажмите **Save**
7. Через несколько минут ваш дашборд будет доступен по адресу:
   ```
   https://[ваш-username].github.io/[название-репозитория]/
   ```
   
   **Важно**: После публикации на GitHub Pages проблема CORS будет решена, так как файлы будут обслуживаться через HTTPS с домена github.io

### Вариант 2: Через Git командную строку

```bash
# Инициализация репозитория
git init
git add index.html README.md METRICS_MAPPING.md roc_logo.png emco_logo.png photos/
git commit -m "Initial commit: ROC Analytics Dashboard"

# Добавление удаленного репозитория
git remote add origin https://github.com/[ваш-username]/[название-репозитория].git
git branch -M main
git push -u origin main
```

Затем настройте GitHub Pages через веб-интерфейс (см. Вариант 1, шаги 3-7).

**Подробные инструкции по настройке GitHub Pages см. в файле `GITHUB_PAGES_SETUP.md`**

## 📱 Использование

### ⚠️ ВАЖНО: Запуск через локальный веб-сервер

**Не открывайте HTML файл напрямую!** Это вызовет ошибки CORS. Запустите через локальный веб-сервер:

#### Вариант 1: Python (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

Затем откройте в браузере: `http://localhost:8000/index.html`

#### Вариант 2: Node.js

```bash
npx http-server -p 8000
```

Затем откройте в браузере: `http://localhost:8000/index.html`

#### Вариант 3: VS Code Live Server

1. Установите расширение "Live Server" в VS Code
2. Правой кнопкой на `index.html` → "Open with Live Server"

#### Вариант 4: GitHub Pages (для продакшена)

См. раздел "Публикация на GitHub Pages" выше.

### После запуска:

1. Дашборд автоматически загрузит данные из Google Таблицы
2. Данные обновляются каждые 15 секунд автоматически
3. При ошибках подключения отображается уведомление с возможностью повтора

## 🔍 Индикаторы состояния

- **Зеленый индикатор** (внизу справа): Подключение установлено, данные загружаются успешно
- **Оранжевый индикатор**: Временные проблемы с подключением
- **Красный индикатор**: Критическая ошибка (нет доступа к таблице, таблица не найдена)

## ⚙️ Настройка интервала обновления

В файле `index.html` найдите конфигурацию:

```javascript
UPDATE_INTERVAL: 15000, // в миллисекундах (15 секунд)
```

Измените значение на нужное (в миллисекундах):
- 5000 = 5 секунд
- 30000 = 30 секунд
- 60000 = 1 минута

## 🛠️ Обработка ошибок

Дашборд автоматически обрабатывает следующие ситуации:

- **Таймаут запроса**: Повторная попытка через 5 секунд (до 3 попыток)
- **Сетевые ошибки**: Автоматический повтор при восстановлении соединения
- **Ошибка доступа (403)**: Уведомление о необходимости опубликовать таблицу
- **Таблица не найдена (404)**: Уведомление о проверке ID таблицы
- **Потеря интернет-соединения**: Автоматическое восстановление при появлении сети

## 📊 Структура метрик

### Общие метрики (Central Card)
- Количество рекомендаций
- Объёмы (тыс. м³)
- Финансовый результат (млн ₽)

### BALANCE (Балансировка)
- Рекомендаций внутри звена
- Дефицит / профицит самосвалов
- Своевременный сход с линии
- Отреагировано нарушений
- Эффект (минут)

### RAM (Дороги)
- Выявлено дорожных аномалий
- Директив на улучшение дорожных условий (2 типа)
- Эффект (км/ч)

### MAS (Простои)
- Действий ROC
- Отреагировано простоев АС
- Отреагировано простоев ЭВ
- Выявленных ошибок в работе ИИ-агентов
- Эффект (минут)

## 🐛 Решение проблем

### Данные не загружаются

1. **Проверьте доступ к таблице**:
   - Убедитесь, что таблица опубликована для просмотра
   - Проверьте, что ID таблицы указан правильно в конфигурации

2. **Проверьте консоль браузера**:
   - Откройте Developer Tools (F12)
   - Перейдите на вкладку Console
   - Ищите сообщения об ошибках

3. **Проверьте CORS**:
   - ⚠️ **ГЛАВНАЯ ПРИЧИНА**: Если файл открыт как `file://`, браузер блокирует запросы из-за CORS
   - **РЕШЕНИЕ**: Запустите через локальный веб-сервер (см. раздел "Использование")
   - Google Sheets разрешает запросы с любых доменов для публичных таблиц, но НЕ с `file://`

### Ошибка "Доступ запрещен"

- Убедитесь, что таблица опубликована: **Настройки доступа** → **"Все, у кого есть ссылка"**
- Проверьте, что в настройках доступа установлен уровень **"Читатель"** или выше

### Данные обновляются слишком часто/редко

Измените `UPDATE_INTERVAL` в конфигурации (см. раздел "Настройка интервала обновления")
